Contributing

Help build the archive — submit requests, documents, agency updates, or template improvements.

What you can submit

  • A new public records request entry (with MuckRock link or direct filing details).
  • An update to a pending request (status change, partial production, denial, etc.).
  • A newly released document or production.
  • A correction to agency metadata.
  • A request template improvement.
  • A link to a public agency policy, annual report, or official public document.
  • A proposed neutral finding supported by primary-source documents.

How to contribute via GitHub

The easiest way to contribute is a pull request against the site-src repository. See the README for step-by-step instructions on updating requests, adding documents, or creating a new agency profile.

Contribute by email

Email intake submissions@alprnebraska.org

For timely handling, emailed submissions should include the same information as the pull request template above: agency/jurisdiction, source URL or attached record, date obtained, a proposed factual description, and the primary-source citation.

Contributor expectations

Send public-records request materials, agency correspondence, released records, links to official policies or reports, or corrections. Do not send raw ALPR data, individual license plate information, live locations, investigative case material, sensitive personal information, or information obtained unlawfully.

Submissions may be edited, rejected, or redacted before publication. Contributors retain responsibility for the lawful acquisition and submission of all materials.

Privacy

Email submissions and GitHub contributions may contain personal contact information or other metadata. The project uses submitted material only to evaluate, verify, communicate about, and potentially publish public-interest records content. Materials are reviewed before publication, but contributors should not send sensitive personal information, raw ALPR data, or non-public investigative material.

Scope and limitations: This project seeks public administrative and accountability records relating to ALPR systems, including policies, procurement, installation, retention, statutory reporting, audits, and information-sharing agreements. It does not seek to publish raw license-plate capture data or personal information protected from public disclosure.

Public records requests filed under the Nebraska Public Records Act, Neb. Rev. Stat. §§ 84-712 through 84-712.09. Requests submitted via MuckRock. Last updated: September 10, 2026.
