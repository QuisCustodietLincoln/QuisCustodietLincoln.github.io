Nebraska ALPR Transparency Project

ALPR Nebraska

An independent public-interest archive tracking public records requests and released documents on how Nebraska governmental agencies acquire, operate, and oversee automated license plate reader (ALPR) systems.

Contributing
File a request, submit documents, update an agency profile, or improve a template.

Scope and limitations: This project seeks public administrative and accountability records relating to ALPR systems, including policies, procurement, installation, retention, statutory reporting, audits, and information-sharing agreements. It does not seek to publish raw license-plate capture data or personal information protected from public disclosure.

Public records requests filed under the Nebraska Public Records Act, Neb. Rev. Stat. §§ 84-712 through 84-712.09. Requests submitted via MuckRock. Last updated: September 10, 2026.
